[고정 조회 구간: 16:46:10~16:51:40 KST](http://localhost:3000/d/ad4t9kv/renegade-backend-overview?from=2026-11-05T07:46:10.000Z&to=2026-11-05T07:51:40.000Z&timezone=browser)

아래는 사용자가 제공한 화면을 읽은 근사값이다. 실제 k6 실행보다 넓은 조회 구간이며, 화면의 요청률·지연 시간에는 이동 구간 집계가 적용된다.

- API 요청률은 부하 구간에서 약 1,200 req/s를 유지했다. 표시된 5xx와 HikariCP 대기 스레드는 0이었다.
- HikariCP 사용 중 커넥션은 대체로 1~2개, 유휴는 8~9개였다. 평균 획득 시간 패널은 일부 구간에서 약 0.016 ms까지 올라갔으나, 이것만으로 커넥션 풀 병목으로 판단하지 않는다.
- 서버 p95는 초반 약 1.9 ms에서 약 1.6~1.7 ms, p99는 초반 약 3.3 ms에서 약 2.3~2.5 ms로 내려왔다. k6 전체 실행 백분위와 구분한다.
- JVM CPU 시계열은 낮은 사용률로 표시됐다. 정확한 평균·최댓값은 원시 지표를 조회하지 않아 미확인이다.
- JVM 스레드 수가 중간에 약 37개에서 55개로 증가했다. 힙은 대략 36~71 MiB 범위에서 오르내렸다. 스레드 증가 원인은 이 자료만으로 확정하지 않는다.
- 저장 결과 패널은 success 294,009, failure 0이었다.
