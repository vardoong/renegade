### 시작 구간과 VU 경고 대조

- VU 경고는 21:59:07이다. 화면상 초반 지연과 커넥션 획득 시간 상승이 관측되므로 시작 구간의 서버 처리 지연은 조사할 후보가 된다.
- 같은 시각으로 표시된 CSV 표본은 DB CPU 46.27%, k6 CPU 46.0%다. 다만 CSV 시각은 조회 시작 시각이며 두 값의 집계 방식도 달라 경고 순간의 CPU 상태라고 단정하지 않는다.
- Prometheus 수집 주기는 15초이고 지연·GC·획득 시간 패널에는 구간 집계가 적용된다. 따라서 21:59:07의 짧은 정체를 정확히 포착했거나 원인을 설명했다고 볼 수 없다.
- 대기 스레드 0과 낮은 JVM CPU 표시는 지속적인 풀 대기·전체 CPU 포화의 근거가 보이지 않는다는 의미다. 일시적인 커넥션 대기, 특정 스레드·코어 정체, k6 스케줄링 지연을 배제하지 않는다.
- 현재 관측은 “초반 지연 이후 안정화되는 양상”을 지지한다. 예열 부족·JIT·커넥션 풀·GC 중 어느 하나를 원인으로 확정할 자료는 부족하다. 스레드 증가가 지연의 원인인지 결과인지도 미확정이다.
